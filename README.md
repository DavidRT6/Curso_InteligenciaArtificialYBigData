# Repositorio del Máster en Inteligencia Artificial y Big Data
Este repositorio recopila los proyectos desarrollados durante el Máster en Inteligencia Artificial y Big Data. Cada carpeta corresponde a una de las asignaturas cursadas, con sus respectivos materiales, notebooks y prácticas.

## Estructura del proyecto
La organización del repositorio sigue la estructura del plan de estudios del Máster. Cada carpeta lleva el nombre de una asignatura:
- Big Data aplicada.
- Modelos de Inteligencia Artificial.
- Programación de Inteligencia Artificial.
- Sistemas de aprendizaje automático.
- Sistemas de Big Data.

## Tecnologías y herramientas utilizadas
A lo largo del Máster, he utilizado diferentes herramientas y tecnologías para crear, analizar y desplegar soluciones de Inteligencia Artificial y Big Data.
Las más destacables son:
-   **Lenguajes de programación:** Python, Scala, R.

-   **Frameworks de Machine Learning:** Scikit-learn, Numpy, Pandas, Matplotlib, Seaborn, TensorFlow, Keras, Flask.
    
-   **Big Data:** Hadoop, NiFi, Spark, Flink, Kafka, Databricks.
    
-   **Bases de datos:** MongoDB.
    
-   **Visualización:** PowerBI.
    
-   **Otros:** Jupyter, Docker, Webots.

## Objetivo
El propósito de este repositorio es mostrar los conocimientos adquiridos durante el Máster, abarcando desde el tratamiento de datos masivos hasta el desarrollo e implementación de modelos de IA.
